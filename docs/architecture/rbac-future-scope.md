# Evolução de escopo

O perfil Gestor de Setor exige, além da permissão de módulo, escopo de dados por equipe. A fundação atual já impede travessia entre empresas; a restrição exata aos subordinados será ligada quando a identidade `User` ↔ `HrEmployee` for persistida explicitamente. Até lá, esse perfil não deve ser homologado para produção com acesso a dados sensíveis.
