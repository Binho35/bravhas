# RBAC e proteção de dados

A matriz adota menor privilégio: o profissional recebe somente os recursos e ações necessários à função. Folha, medidas disciplinares, desligamentos, auditoria e configurações são tratados como recursos sensíveis. A autorização não substitui políticas internas, retenção documental ou demais controles de LGPD, mas reduz exposição operacional indevida.
