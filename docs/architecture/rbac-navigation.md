# Rotas administrativas

- `/rh/configuracoes` — central MASTER.
- `/rh/configuracoes/perfis` — matriz de módulos e ações.
- `/rh/configuracoes/acessos` — atribuição de perfil por profissional.

As três rotas exigem OWNER/ADMIN no servidor nesta fase. Na camada de negócio, esses usuários representam os administradores MASTER responsáveis por CEO/Head Administrativo.
