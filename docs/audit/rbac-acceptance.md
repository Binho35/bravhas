# Critérios de aceite

O MASTER consegue abrir a central, visualizar os perfis padrão, alterar a matriz de um perfil não-master e atribuir esse perfil a um usuário da mesma empresa. Um usuário não-master sem a permissão solicitada deve receber negação server-side. CEO/Head devem permanecer integrais. Nenhuma associação entre empresas deve ser aceita.
